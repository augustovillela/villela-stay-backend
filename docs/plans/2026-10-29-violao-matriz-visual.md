# Reconstrução visual do livro de violão

## Regra editorial

Nenhuma fotografia ou diagrama será usado apenas para preencher espaço. Cada recurso visual deve responder a uma pergunta do capítulo e aparecer imediatamente depois da explicação correspondente. Fotografias de performance serão reservadas para postura, repertório, gravação e apresentação; técnica, harmonia e leitura usarão diagramas próprios.

## Famílias visuais por capítulo

| Capítulos | Recursos principais |
| --- | --- |
| 1–4 | anatomia anotada, acessórios, afinador, postura e ergonomia |
| 5–8 | mãos em detalhe, dedilhados, diagramas de acordes e trocas com dedos numerados |
| 9–13 | grades de subdivisão, setas de batida, mapas de acentos e levadas específicas |
| 14–18 | cifras, diagramas de pestana, tablatura anotada, pauta e braço com notas |
| 19–24 | escalas no braço, intervalos, campos harmônicos, voicings e condução de vozes |
| 25–28 | padrões de arpejo, mapas de polegar/dedos, fingerstyle e técnicas de expressão |
| 29–33 | repertório visual, formas, levadas e vocabulário de estilos |
| 34–38 | frases, alvos harmônicos, transcrição, riffs e estruturas de introdução/final |
| 39–42 | arranjo em camadas, voz e violão, formação de grupo e sinal de gravação |
| 43–45 | calendário de estudo, rubricas de avaliação e projeto final documentado |

## Critério de qualidade

Cada capítulo deverá conter pelo menos três recursos visuais diferentes, vinculados a seções distintas: um para compreender, um para executar e um para aplicar. O capítulo só será considerado pronto depois de verificar se o visual realmente corresponde ao texto, se a legenda ensina a leitura e se não é uma repetição genérica de outro capítulo.
