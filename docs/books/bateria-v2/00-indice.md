## Como usar o índice

O estudante pode seguir a ordem completa ou retornar diretamente a uma parte conforme a necessidade. Para cada capítulo:

1. leia os objetivos;
2. confira os pré-requisitos;
3. pratique os exercícios lentamente;
4. aplique o conceito em um groove ou repertório;
5. faça o diagnóstico;
6. registre o próximo passo.

As mídias profissionais de áudio, vídeo e exercícios sincronizados serão acrescentadas em uma etapa posterior. O manuscrito textual está organizado para receber esses materiais sem alterar a sequência pedagógica.
