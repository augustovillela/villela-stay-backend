# Capítulo 9 — Acordes abertos

## Objetivos

Montar acordes essenciais, ouvir cada nota e trocar entre formas sem interromper o pulso.

**Nível:** iniciante. **Pré-requisitos:** Parte 2.

## Como ler um diagrama

As linhas verticais representam as cordas, da sexta à primeira; as horizontais representam trastes. Um ponto indica a casa e o dedo; `O` é corda solta; `X` é corda abafada.

```text
        E     A     D     G     B     e
C       X     3     2     0     1     0
G       3     2     0     0     0     3
D       X     X     0     2     3     2
A       X     0     2     2     2     0
E       0     2     2     1     0     0
Em      0     2     2     0     0     0
Am      X     0     2     2     1     0
Dm      X     X     0     2     3     1
```

Os números acima são as casas, não necessariamente os dedos. Monte a forma, toque corda por corda e corrija qualquer nota abafada antes de fazer a batida completa.

## Progressões de entrada

```text
| C  | G  | Am | F  |
| D  | A  | E  | E  |
| Am | Dm | G  | C  |
```

Toque quatro pulsos por acorde a 50 bpm. Depois troque a cada dois pulsos. O desafio é preparar o próximo formato antes do primeiro pulso do novo compasso.

## Sétimas e cor

E7, A7 e B7 introduzem tensão dominante. Compare `E` e `E7`: a pequena mudança de uma nota já altera a direção harmônica. Use a audição para perceber a necessidade de resolução, não apenas a forma visual.

## Erros comuns

- tocar sem conferir todas as cordas;
- levantar todos os dedos entre acordes;
- apertar demais a pestana inexistente;
- acelerar a troca e perder o compasso.

## Checklist

- [ ] Leio X, O e números no diagrama.
- [ ] Monto C, G, D, A, E, Em, Am e Dm.
- [ ] Troco acordes com metrônomo.
- [ ] Ouço a diferença entre acorde maior, menor e dominante.
