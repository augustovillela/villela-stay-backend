# Anexo 6 — Projeto final

Escolha uma música para análise ou crie uma composição autoral. Identifique tonalidade e estrutura, crie base, riffs ou power chords, introdução, variação de refrão, solo e timbre. Grave ou apresente a execução.

## Critérios

| Critério | Pergunta |
|---|---|
| afinação | as notas e acordes estão estáveis? |
| ritmo | o pulso permanece consistente? |
| timbre | o som serve à função? |
| dinâmica | há contraste entre seções? |
| musicalidade | a ideia é comunicada com clareza? |

Repita o projeto depois de uma semana e compare as duas versões com os mesmos critérios.
