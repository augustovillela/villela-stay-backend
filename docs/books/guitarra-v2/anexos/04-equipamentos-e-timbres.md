# Anexo 4 — Guia de equipamentos e timbres

## Cadeia de sinal

```text
guitarra → afinador → compressor → ganho → modulação → delay → reverb → amplificador/interface
```

## Diagnóstico de timbre

Antes de comprar equipamento, descreva o problema: falta de ataque, excesso de graves, ruído, pouca sustentação ou falta de espaço. Só depois escolha um controle ou efeito para testar.
