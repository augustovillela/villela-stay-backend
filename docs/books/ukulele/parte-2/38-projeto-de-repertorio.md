# Capítulo 38 — Projeto de repertório

## Objetivos de aprendizagem

Ao terminar este capítulo, você será capaz de escolher uma peça, definir uma versão tocável, organizar etapas de estudo, registrar evidências e preparar uma apresentação curta.

## Pré-requisitos

Tenha estudado acompanhamento, melodia, arranjo, gravação e planejamento. Este projeto não exige usar todas as técnicas; exige escolher as que realmente ajudam a peça.

## Escolha da peça

Escolha uma canção que desperte interesse e tenha dificuldade compatível com o momento. Registre título, tonalidade, andamento aproximado, estrutura e versão desejada: acompanhamento, melodia ou arranjo instrumental.

## Etapa 1 — Mapa

Escreva a forma completa, os acordes principais, as levadas e os pontos de transição. Marque os compassos que exigem estudo específico. O mapa será atualizado conforme você descobrir novas dificuldades.

## Etapa 2 — Versão básica

Prepare uma versão que possa ser tocada do início ao fim com segurança. Use acordes simples e uma levada estável. Esta versão é a base de recuperação caso a versão enriquecida fique instável.

## Etapa 3 — Refinamento

Adicione uma mudança de dinâmica, uma introdução, um interlúdio ou uma linha melódica. Acrescente um recurso por vez e verifique se ele melhora a música. Não acumule efeitos apenas para demonstrar técnica.

## Etapa 4 — Gravação e avaliação

Faça três tomadas completas. Avalie pulso, clareza, forma, dinâmica e intenção. Escolha um ajuste prioritário, pratique-o e faça uma nova gravação para comparação.

## Etapa 5 — Apresentação

Defina entrada, posição do instrumento, contagem, final e duração. Faça uma simulação sem interromper e prepare uma frase curta para apresentar a peça. A apresentação é parte do aprendizado.

## Diagnóstico

- **Peça grande demais:** reduza a forma ou escolha uma versão básica.
- **Dificuldade espalhada:** agrupe problemas por seção.
- **Refinamento instável:** retire o último recurso acrescentado.
- **Avaliação vaga:** use critérios e evidências observáveis.

## Desafio do capítulo

Conclua um projeto de repertório de duas a quatro semanas. Entregue mapa, versão básica, versão refinada, registro de prática, uma gravação e uma avaliação final.

## Checklist

- [ ] Escolhi uma peça compatível com meu momento.
- [ ] Escrevi mapa, acordes e transições.
- [ ] Preparei uma versão básica completa.
- [ ] Acrescentei refinamentos com intenção.
- [ ] Gravei, avaliei e preparei uma apresentação.

## Rotina sugerida

1. Um dia de escolha e mapeamento.
2. Três sessões de versão básica.
3. Três sessões de refinamento.
4. Uma sessão de gravação e avaliação.
5. Uma sessão de simulação e apresentação.
